# 自动化消息操作说明

平台：[开发者后台](https://dev.233leyuan.com/home)

## 链路

1. 在开发者后台开通自动化消息：选模板类型，填写结果回调地址。
2. 开通通过后创建消息模板。标题和正文可以带占位符，保存后得到模板 ID。
3. 游戏内用联运 SDK 查询用户的消息通知权限；还没授权时再申请，由乐园拉起授权弹窗。
4. 游戏服务端创建消息发送任务，传入模板 ID 和占位符内容。
5. 平台发送站内信和 Push。任务结束后，把发送结果 POST 到第 1 步填写的回调地址。

## 1. 开通自动化消息

上传游戏后，打开 [开发者后台](https://dev.233leyuan.com/home)，进入 **发版管理 → 自动化消息**，先开通。开通通过后，才能创建模板、创建发送任务。

1. **模板类型**：勾选本游戏要用的类型。可选：互动通知提醒、好友私信提醒、福利活动提醒、系统通知提醒。后面创建模板时，只能选这里已开通的类型。
2. **结果回调地址**：用来接收消息任务的发送结果。地址要求和返回格式见 [自动化消息回调地址配置说明](./auto_message_callback.md)。

[https://release.233leyuan.com/online/f94b36e7873ff809e4e338ae9b594e9b/xl.webp](https://release.233leyuan.com/online/f94b36e7873ff809e4e338ae9b594e9b/xl.webp)

## 2. 创建消息模板

开通通过后，在同一入口创建消息模板。

1. **标题 / 正文**可以写入占位符。创建消息任务时再传入每个占位符的实际内容。
2. 创建成功后生成 **模板 ID**。创建消息任务时传入该 ID。模板须已生效，且类型在本游戏已开通的消息权限内。同一模板会同时下发站内信和 Push。

[https://release.233leyuan.com/online/c367e5436a42e0b5266615bc9bae3687/xl.webp](https://release.233leyuan.com/online/c367e5436a42e0b5266615bc9bae3687/xl.webp)

## 3. 联运 SDK 获取用户通知权限

用户未授权对应类型时，发送会被拒绝。弹窗由乐园拉起。游戏在合适场景接入联运 SDK：

1. **查询消息类型通知权限**：看用户是否已允许接收对应类型的通知。
2. **申请用户获取消息类型通知权限**：尚未授权时调用，由乐园拉起授权弹窗。

## 4. 创建消息发送任务

游戏服务端用模板 ID、占位符内容和收件人创建任务。接口立即返回任务 ID，发送是否成功等回调。

见 [创建消息发送任务](./create_message_task.md)。
