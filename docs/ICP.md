# ICP备案

233乐园可以为游戏小程序代为备案。备案成功并获得小程序ICP备案号后才能继续在平台上架；提报期间，请关注审核进度，审核通过后可通过备案管理系统[https://beian.miit.gov.cn](https://beian.miit.gov.cn/) 查看备案结果

## 备案前准备

### 前置备案

> **根据管局规定，无版号游戏申报ICP备案，必须要有中宣部游戏小程序备案，即前置备案**
>
> **周期**：每月20号（逢周末、节假日顺延）批量提交申报一次
>
> **中宣部审核完成时间**：30-40天左右
>
> 相关游戏审核结果由平台运营&商务同步

#### 入口

在开发者后台创建游戏后，菜单处**点击游戏资质，选择游戏上线运营登记，选择无版号，去登记**进入填写页面

#### 所需材料

##### 作品备案信息申请

基础游戏信息，必须如实填写

- 作品名称（需与软著一致）
- 游戏内容类别
- 盈利模式
- 是否有其他运营平台
- 是否在其他平台提交过备案申请
- 软著游戏名称（需与软著一致）
- 软著登记号（需与软著一致）
- 软著著作权人（需与软著一致）
- 软著图片（只支持JPG/PNG格式,大小不超过5MB）
- 授权书图片（只支持JPG/PNG格式,大小不超过5MB）
- 是否联网
- 供监管审核的高级账号

**材料里不能包含：血腥、恐怖、击杀、爆炸、耽美等不符合社会主义价值观内容，歧义内容也建议调整**；**呈现的备案材料以正向**进行图文介绍

- **需要包含的内容**

  > **格式要求**：
  >
  > 字体：宋体
  >
  > 字号：①大标题→二号 ②中标题→三号 ③模块内容→小四
  >
  > 只支持DOCX/DOC格式

  以word文档的形式上传，文档总字数需1000字以上并配上游戏内截图主要内容为：

  1. 游戏背景
  2. 人物介绍 （主要角色、其他NpC等）
  3. 游戏场景 （游戏主界面、游戏战斗背景、过场动画、特色场景图等）
  4. 主要情节
  5. 游戏玩法
  6. 游戏功能（如转盘、皮肤、签到等系统介绍）
  7. 游戏特点
  8. 游戏使用方法

### 备案审核

| 流程 | 详细备注 |
| --- | --- |
| 平台初审 | 开发者在平台提交小程序备案信息后，平台将会在1-2个工作日内完成初审（具体请以实际审核时间为准），审核结果将以站内信、模板消息等形式通知管理员。 在平台初审的过程中，请备案相关人员保持电话畅通，以便平台对你提交的备案信息进行核验。 |
| 工信部短信核验 | 平台初审通过后，备案信息填写的责任人手机号码会收到工业和信息化部【12381】号码下发的核验短信，需要对应责任人点击所收到短信内的链接进入到工信部备案系统，完成短信核验；2、短信核验完成后，小程序备案申请进入省通信管理局审核流程。 特别说明： 【12381】下发的核验短信有效期为24小时，若核验时提示验证码错误或无效，可在工信部备案系统（[https://beian.miit.gov.cn/#/Integrated/index](https://beian.miit.gov.cn/#/Integrated/index)）触发一次短信重发，若24小时内未核验成功，备案申请将被工信部系统自动驳回，开发者需要到平台重新提交备案申请。 |
| 通管局审核 | 各省通信管理局将在1-20个工作日内（具体以实际审核时间为准）完成审核，审核结果以站内信、模板消息、短信等形式通知。 |
| 备案成功 | 管局审核通过后，将下发的小程序备案号，代表你的小程序已完成备案，可以进入下一步版本发布等流程。 |
